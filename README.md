# GTM Library

A hands-on library of GTM (go-to-market) engineering use cases, built with Claude Code.

I'm building a GTM and GEO business in public. GEO (generative engine optimization) is how a brand gets found and recommended by search engines in the era of AI (e.g. ChatGPT, Perplexity, Gemini and Claude). The GTM use cases turn that visibility into tangible business results (e.g. pipeline).

Each use case ships:
- a **case study** (problem → build → result → lesson)
- a **skill or plugin** others can install
- a **one-page pitch**
- a **post** about what I learned
